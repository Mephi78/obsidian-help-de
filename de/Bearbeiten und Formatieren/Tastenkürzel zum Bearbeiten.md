Erfahre, mit welchen Tastenkombinationen du dich durch deine Notizen bewegen und diese bearbeiten kannst. Du kannst auch [[Tastenkürzel|eigene Tastenkürzel]] festlegen.

## Windows und Linux

### Häufig verwendete Aktionen

| Aktion                     | Tastenkürzel                             |
| -------------------------- | ---------------------------------------- |
| Kopieren                   | `Strg+C`                                 |
| Ausschneiden               | `Strg+X`                                 |
| Einfügen                   | `Strg+V`                                 |
| Einfügen ohne Formatierung | `Strg+Umschalt+V`                        |
| Rückgängig                 | `Strg+Z`                                 |
| Wiederholen                | `Strg+Umschalt+Z` or `Strg+Y`            |
| Absatz kopieren            | `Strg+C` (wenn kein Text ausgewählt ist) |
| Absatz ausschneiden        | `Strg+X` (wenn kein Text ausgewählt ist) |

### Text formatieren

| Aktion        | Tastenkürzel |
| ------------- | ------------ |
| Fetter Text   | `Strg+B`     |
| Kursiver Text | `Strg+I`     |

### Text bearbeiten

| Aktion                     | Tastenkürzel                                      |
| -------------------------- | ------------------------------------------------- |
| Neue Zeile einfügen        | `Eingabetaste`                                    |
| Vorheriges Zeichen löschen | `Rücktaste`                                       |
| Nächstes Zeichen löschen   | `Entf`                                            |
| Vorheriges Wort löschen    | `Strg+Rücktaste`                                  |
| Nächstes Wort löschen      | `Strg+Entf`                                       |
| Zeile löschen              | `Strg+Umschalt+K` (wenn kein Text ausgewählt ist) |

### Im Text bewegen

| Aktion                                                 | Tastenkürzel              |
| ------------------------------------------------------ | ------------------------- |
| Cursor um ein Zeichen bewegen                          | `Pfeil nach links/rechts` |
| Cursor an den Anfang des vorhergehenden Wortes bewegen | `Strg+Pfeil nach links`   |
| Cursor ans Ende des nächsten Wortes bewegen            | `Strg+Pfeil nach rechts`  |
| Cursor an den Zeilenanfang bewegen                     | `POS1`                    |
| Cursor ans Zeilenende bewegen                          | `Ende`                    |
| Cursor in die vorhergehende Zeile bewegen              | `Pfeil nach oben`         |
| Cursor in die nächste Zeile bewegen                    | `Pfeil nach unten`        |
| Cursor an den Anfang der Notiz bewegen                 | `Strg+POS1`               |
| Cursor ans Ende der Notiz bewegen                      | `Strg+Ende`               |
| Cursor auf die vorige Seite bewegen                    | `Bild nach oben`          |
| Cursor auf die nächste Seite bewegen                   | `Bild nach unten`         |

### Text auswählen

| Aktion                                                     | Tastenkürzel                       |
| ---------------------------------------------------------- | ---------------------------------- |
| Auswahl aufheben                                           | `Escape`                           |
| Alles auswählen                                            | `Strg+A`                           |
| Auswahl um ein Zeichen erweitern                           | `Umschalt+Pfeil nach links/rechts` |
| Auswahl bis zum Anfang des vorhergehenden Wortes erweitern | `Strg+Umschalt+Pfeil nach links`   |
| Auswahl bis zum Ende des nächsten Wortes erweitern         | `Strg+Umschalt+Pfeil nach rechts`  |
| Auswahl bis zum Zeilenanfang erweitern                     | `Umschalt+POS1`                    |
| Auswahl bis zum Zeilenende erweitern                       | `Umschalt+Ende`                    |
| Auswahl bis zum Anfang der Notiz erweitern                 | `Strg+Umschalt+POS1`               |
| Auswahl bis zum Ende der Notiz erweitern                   | `Strg+Umschalt+Ende`               |
| Auswahl um die vorige Seite erweitern                      | `Umschalt+Bild nach oben`          |
| Auswahl um die nächste Seite erweitern                     | `Umschalt+Bild nach unten`         |

## macOS

### Häufig verwendete Aktionen

| Aktion                     | Tastenkürzel                            |
| -------------------------- | --------------------------------------- |
| Kopieren                   | `Cmd+C`                                 |
| Ausschneiden               | `Cmd+X`                                 |
| Einfügen                   | `Cmd+V`                                 |
| Einfügen ohne Formatierung | `Cmd+Umschalt+V`                        |
| Rückgängig                 | `Cmd+Z`                                 |
| Wiederholen                | `Cmd+Umschalt+Z`                        |
| Absatz kopieren            | `Cmd+C` (wenn kein Text ausgewählt ist) |
| Absatz ausschneiden        | `Cmd+X` (wenn kein Text ausgewählt ist) |

### Text formatieren

| Aktion | Tastenkürzel |
| ---- | ---- |
| Fetter Text | `Cmd+B` |
| Kursiver Text | `Cmd+I` |

### Text bearbeiten

| Aktion                       | Tastenkürzel                                     |
| ---------------------------- | ------------------------------------------------ |
| Neue Zeile einfügen          | `Eingabetaste`                                   |
| Vorheriges Zeichen löschen   | `Rücktaste`                                      |
| Nächstes Zeichen löschen     | `Entf`                                           |
| Vorheriges Wort löschen      | `Option+Rücktaste`                               |
| Nächstes Wort löschen        | `Option+Entf`                                    |
| Löschen bis zum Zeilenanfang | `Cmd+Rücktaste`                                  |
| Löschen bis zum Zeilenende   | `Cmd+Entf`                                       |
| Zeile löschen                | `Cmd+Umschalt+K` (wenn kein Text ausgewählt ist) |
