Die Catalyst Lizenz ermöglicht dir Zugang zu Beta-Versionen. Um die Weiterentwicklung von Obsidian mit dem [Einmalkauf einer Catalyst Lizenz](https://obsidian.md/buy/catalyst) zu unterstützen, benötigst du ein Obsidian-Konto.

## Catalyst-Stufen

Catalyst gibt es in drei Stufen, je nach Höhe der Zuwendung: *Insider*, *Supporter* und *VIP*

| Benefits                                                                             | Insider | Supporter |   VIP    |
| ------------------------------------------------------------------------------------ | :-----: | :-------: | :------: |
| Früher Zugang zu neuen Versionen (Insider-Build)                                     |    ✓    |     ✓     |    ✓     |
| Zugang zu den exklusiven Entwickler-Kanälen `#insider-desktop` und `#insider-mobile` |    ✓    |     ✓     |    ✓     |
| Zugang zum exklusiven Lounge-Kanal `#vip-lounge`                                     |         |     ✓     |    ✓     |
| Insider-Abzeichen                                                                    |    ✓    |           |          |
| Unterstützer-Abzeichen                                                               |         |     ✓     |          |
| VIP-Abzeichen                                                                        |         |           |    ✓     |
| **einmalige Zuwendung (USD)**                                                        | **$25** |  **$50**  | **$100** |


> [!info] Erhöhe deine Catalyst-Stufe
> Wenn du bereits eine Catalyst Lizenz besitzt, kannst du diese aufwerten, indem du nur die Preisdifferenz von deiner aktuellen zur gewünschten Stufe zahlst.

## Catalyst-Vorteile nutzen

Mit dem Erwerb einer Catalyst Lizenz erhältst du Zugriff auf einige Vorteile. Erfahre hier, wie du diese aktivierst.

### Forum-Abzeichen erhalten

**Hinweis:** Um dein Obsidian-Konto mit deinem Forum-Benutzerkonto zu verknüpfen, musst du für beide dieselbe E-Mail-Adresse verwenden.

1. Tritt unserem [Forum](https://forum.obsidian.md/) bei.
2. Rufe dein [Obsidian Benutzer-Dashboard](https://obsidian.md/account/catalyst) auf.
3. Unter **Catalyst**, wähle **Get forum badge**.

### Discord-Abzeichen erhalten

1. Tritt unserem [Discord Server](https://discord.gg/veuWUTm) bei.
2. Rufe dein [Obsidian Benutzer-Dashboard](https://obsidian.md/account/catalyst) auf.
3. Unter **Catalyst**, wähle **Get Discord badge**.

### Unseren Insider-Kanälen beitreten

Insider können sich mit dem Obsidian-Team und anderen Insidern in unseren exklusiven Discord-Kanälen austauschen. Du trittst den Insider-Kanälen automatisch bei, nachdem du dein [[#Discord-Abzeichen erhalten]] hast.
