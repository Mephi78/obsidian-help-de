Obsidian hat zwei Seitenleisten, je eine links und rechts. In der ![[lucide-monitor-check.svg#icon]] Desktop Version und auf größeren Tablets enthält die linke Seitenleiste auch die [[Werkzeugleiste]]. In der ![[obsidian-icon-smartphone.svg#icon]] Mobile Version und auf kleineren Tablets sind die Seitenleisten [[#Seitenleisten ein- oder ausblenden|standardmäßig ausgeblendet]].

## Seitenleisten ein- oder ausblenden

![[lucide-monitor-check.svg#icon]] Desktop und größere Tablets: Blende eine versteckte Seitenleiste ein über das Symbol zum **Aufklappen** links ( ![[obsidian-icon-side-bar-left.svg#icon]] ) bzw. rechts ( ![[obsidian-icon-side-bar-right.svg#icon]] ). Das Symbol verändert sich, zum **Zuklappen** der Seitenleiste klicke es einfach erneut.

![[obsidian-icon-smartphone.svg#icon]] Mobile und kleinere Tablets: Wische nach rechts bzw. links oder tippe das Symbol zum **Aufklappen** ( ![[obsidian-icon-side-bar-left.svg#icon]] ) bzw. halte das **Menü-Symbol** ( ![[lucide-ellipsis-vertical.svg#icon]] ) in der Notiz länger, um eine versteckte Seitenleiste einzublenden. Zum **Zuklappen** einer Seitenleiste wische wieder nach links bzw. rechts.

## Tabs

Tabs (auch: Registerkarten) werden auf dem ![[lucide-monitor-check.svg#icon]] Desktop durch klickbare Symbole am oberen Rand einer Seitenleiste repräsentiert.

Wechsle zwischen Tabs, indem du auf dem ![[lucide-monitor-check.svg#icon]] Desktop das entsprechende Symbol anklickst. Beim Überfahren mit dem Mauszeiger erscheint ein Hinweis, was sich hinter dem jeweiligen Symbol verbirgt. In der ![[obsidian-icon-smartphone.svg#icon]] Mobile Version kannst du den Titel des aktuell sichtbaren Tabs anklicken und aus der Liste einen anderen auswählen.

In jedem Seitenleistenbereich wird nur jeweils eine Registerkarte gleichzeitig angezeigt. Einige Aktionen bewirken, dass ein bestimmter Tab automatisch angezeigt wird, bspw. wenn du auf einen [[Tags|Tag]] klickst.

Standardmäßig erstellen Erweiterungen nur neue Tabs, keine neuen [[#Tab-Gruppen]].

### Tabs schließen

Die meisten Tabs können auf dem ![[lucide-monitor-check.svg#icon]] Desktop über ihr Kontextmenü (Rechtsklick auf das Tab-Symbol) und Auswahl der Option **Schließen** geschlossen werden.

Lässt ein Tab sich auf diese Weise nicht schließen, kannst du die [[#Seitenleisten ein- oder ausblenden|Seitenleiste komplett ausblenden]] oder überlegen, ob du die entsprechende [[Externe Erweiterungen#Externe Erweiterung deaktivieren|Erweiterung deaktivieren]] möchtest.

In der ![[obsidian-icon-smartphone.svg#icon]] Mobile Version kannst du Tabs schließen, indem du die dazugehörige Erweiterung über die **Einstellungen** ( ![[lucide-settings.svg#icon]] ) deaktivierst.

### Tabs anordnen

Auf dem ![[lucide-monitor-check.svg#icon]] Desktop kannst du Tabs beliebig per Drag & Drop innerhalb der Tab-Gruppe anordnen.

Der hervorgehobene Bereich innerhalb einer Tab-Gruppe zeigt dir, an welcher Stelle ein Tab eingefügt wird, sobald du ihn ablegst.

## Tab-Gruppen

 Auf dem ![[lucide-monitor-check.svg#icon]] Desktop kannst du die Seitenleisten auch in mehrere Tab-Gruppen aufteilen.

### Tab-Gruppen erstellen

Um eine neue Tab-Gruppe per Drag & Drop zu erstellen, ziehe einen Tab oberhalb oder unterhalb einer bestehenden Tab-Gruppe in einer der Seitenleisten, bis ein Bereich der Seitenleiste hervorgehoben wird. Der hervorgehobene Bereich zeigt an, wo die Tab-Gruppe erstellt wird, sobald du den Tab ablegst.

### Tab-Gruppen schließen

Eine Tab-Gruppe wird geschlossen, wenn du alle [[#Tabs schließen|Tabs darin schließt]] oder [[#Tabs anordnen|in eine andere Tab-Gruppe verschiebst]].
